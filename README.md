# Forever Dungeon Quests

A community addon for [Polestar](https://polestar.guide), the guide addon for
World of Warcraft: Forever. It has quest guides for WoW Forever's
dungeons: for each dungeon, one guide per faction that takes every quest of
it, from the first lead-in to the last hand-in, with the run itself boss by
boss. It is a separate addon by creazy231; it is not made or supported by
Polestar.

## What every guide does

- **Every quest of its dungeon in one route.** The lead-ins, the pick-ups,
  one run and every hand-in, in an order that walks you there once.
- **Picks up where you are.** Steps you have already done are passed over,
  so a guide starts wherever your chain stands.
- **One run.** Every quest that needs the dungeon is in your log before you
  go in, so one run is enough; a second only where a follow-up sends you
  back in.
- **What is left out, and why.** Each dungeon's section names the quests a
  guide leaves out: ones that need another dungeon, a raid, a reputation
  grind or a world event, repeatable ones, and city dungeons' quests for the
  other faction.
- **Boss by boss.** Inside, the steps follow the bosses in the order of a
  recorded run where there is one, else in the order of the game's dungeon
  journal, and each step says which kill, drop or object comes there. Every
  quest goal is counted by the quest log, so another order works too.

In Polestar's guide menu (`/polestar guides`), the guides are under
**Community guides** > **Forever Dungeon Quests**, in the Dungeons category,
with one folder per dungeon.

## Next to Polestar's Dungeons window

Polestar's Dungeons window (`/polestar dungeons`, since Polestar 0.4.0) has a
page for many dungeons, with a pick-up guide and a hand-in guide planned for
your character. This addon gives you a dungeon's quests as one fixed route
per faction, from the first lead-in to the last hand-in, with the run in
between.

## Install

- **Polestar Client:** open **Community**, find **Forever Dungeon Quests**
  and press **Install**.
- **By hand:** unzip the release into the game's `Interface/AddOns/` folder,
  next to the `Polestar` folders, so that
  `Interface/AddOns/PolestarPack_forever-dungeon-quests` exists.

Restart the game the first time (a `/reload` does not load a new addon).
**Options > Community guides** (`/polestar packs`) turns the addon on or off.

## Problems and ideas

Report a wrong step to creazy231 on the addon's page,
<https://polestar.guide/community/forever-dungeon-quests>, not to Polestar.

## Where the facts come from

Every quest, NPC, item and reward comes from the game's data as Polestar's
reference data holds it (QuestieDB Forever). Entrances, loot, drops and
where quests start and end inside come from players' recordings collected by
Polestar, and each dungeon's size, levels and bosses from the game client's
own tables. The way through a dungeon comes from a run of my own, recorded
with Polestar's recorder, where I have one, else from the order of the game's
dungeon journal. Nothing comes from websites or other guides.

## For authors

The addon is built from this folder: `pack.json` and the `.guide` files in
`guides/`, in Polestar's guide format. With a Polestar clone (Node 24+,
Lua 5.1, its `forge` built and its reference data built), from this folder:

- `forge guide lint`: checks the guides against the game's data.
- `polestar playtest`: plays every guide to the end.
- `polestar install --pack . --dest <AddOns folder>`: copies it into the game.
- `forge release pack`: writes the release zip to `dist/`.

To add a dungeon, add one guide per faction to `guides/`:

- Guide ids `forever-dungeon-quests/<dungeon>-horde` and
  `forever-dungeon-quests/<dungeon>-alliance`.
- `category Dungeons`, and `folder <the dungeon's name>`.
- Every fact from the game's data, players' recordings or a run of your own,
  and the header says which.

Then raise `version` in `pack.json`. Never change a published guide's id:
players' progress is kept under it.

The Drowned City's guides use quests that QuestieDB Forever has from version
1.1.1 on: reference data built from an older one lacks nine of them.
